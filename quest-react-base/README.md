# Quest React Base

Projeto desenvolvido com **React + Vite** como parte de um exercício de fixação dos conceitos básicos de componentes, props e eventos em React.

## 🧠 Objetivo do projeto

O objetivo deste projeto é praticar:

- Criação de componentes React
- Uso de **props**
- Manipulação de texto com JavaScript
- Estilização inline
- Eventos de clique

## 🧩 Funcionalidades

### 1️⃣ Componente de Texto
- Renderiza um parágrafo na tela
- O texto é transformado para **letras maiúsculas (uppercase)** usando JavaScript
- A **cor do texto/fundo** é recebida via props

### 2️⃣ Componente Button
- Renderiza um botão reutilizável
- Recebe uma prop `label`
- Ao clicar no botão, exibe um **alert** com a mensagem:
  
  > "A label desse botão é <label>"

## 🛠 Tecnologias utilizadas

- React
- Vite
- JavaScript
- CSS
